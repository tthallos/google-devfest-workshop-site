DevFest 的最后一场演讲，是关于 **Chrome DevTools MCP** 的。

在此之前，我对 MCP 这个词完全陌生。演讲结束后，我觉得这可能是今天最实用的一个技术——因为它直接解决了我每天都在面对的问题：**调试**。

## 什么是 MCP？

MCP 的全称是 **Model Context Protocol**（模型上下文协议）。这是 Anthropic 开发的一个开源标准，用于连接 AI 应用程序与外部系统。

你可以把 MCP 想象成 AI 世界的"USB 接口"——它提供了一种标准化的方式，让 AI 可以连接到各种工具和数据源。

在 MCP 出现之前，每个 AI 应用都需要单独开发与外部工具的集成。现在有了 MCP，一个工具只需要实现一次 MCP 接口，就可以被所有支持 MCP 的 AI 应用使用。

## Chrome DevTools MCP 做了什么？

**Chrome DevTools MCP** 是一个 MCP 服务器，它让 AI 编程助手可以：

- 打开和导航网页
- 截取屏幕截图
- 分析网络请求
- 查看控制台日志
- 执行 JavaScript 代码
- 录制和分析性能追踪

换句话说，它让 AI 拥有了一个完整的浏览器，可以像真正的开发者一样调试网页。

## 为什么这很重要？

让我讲一个真实的故事。

上周，我遇到了一个 bug：页面在某些情况下会白屏。我花了两个小时来描述这个问题——

"点击这个按钮后，等待三秒，再点击那个链接，页面就会变白。但如果等待时间少于两秒，就没问题。"

我把这段描述发给 Claude，它给了我五种可能的原因。我一个一个排查，都不对。

问题在哪里？**AI 看不见我的屏幕。** 它只能根据我的文字描述来猜测问题，而我的描述可能遗漏了关键信息。

有了 Chrome DevTools MCP，情况就完全不同了。AI 可以：

1. 自己打开页面
2. 按照步骤重现问题
3. 查看控制台是否有错误
4. 分析网络请求是否异常
5. 截图记录每一步的状态

它不再需要依赖我的描述，它可以自己"看"到问题。

## 实际使用演示

演讲中有一个精彩的演示。演讲者说："帮我找出这个页面为什么加载这么慢。"

AI 做了以下事情：

1. 打开目标页面
2. 启动性能追踪
3. 刷新页面
4. 停止追踪并分析结果
5. 给出报告："主要问题是第三方广告脚本阻塞了页面渲染。建议将其改为异步加载。"

整个过程不到一分钟，而且 AI 给出了具体的文件名和行号。

如果是我自己来做这个分析，至少需要十分钟——打开 DevTools，切换到 Performance 面板，点击录制，刷新页面，等待录制完成，然后一帧一帧地分析火焰图......

## 如何配置

如果你使用 Claude Code、Cursor、VS Code Copilot 或其他支持 MCP 的 AI 工具，配置非常简单。

以 Claude Code 为例：

```bash
claude mcp add chrome-devtools npx chrome-devtools-mcp@latest
```

以 VS Code 为例：

```bash
code --add-mcp '{"name":"chrome-devtools","command":"npx","args":["-y","chrome-devtools-mcp"]}'
```

配置完成后，AI 就可以控制你的浏览器了。

## 安全考虑

这里有一个重要的提醒：**AI 可以完全控制你的浏览器**。

这意味着它可以看到你浏览的所有内容，包括你的登录状态、私人消息等。所以：

1. 不要在使用 MCP 时浏览敏感网站
2. 使用独立的 Chrome 配置文件进行开发
3. 定期检查 AI 的操作日志

演讲者建议使用 `--isolated` 参数来创建一个临时的浏览器配置，这样 AI 使用的浏览器会与你的日常浏览器完全隔离。

## 我的实践体验

演讲结束后，我立刻在自己的项目里试用了这个工具。

我有一个页面，在 Safari 上显示正常，但在 Chrome 上布局有问题。以前我需要自己打开两个浏览器，来回对比。

现在我只需要告诉 AI："帮我对比这个页面在不同窗口尺寸下的显示效果，找出布局问题。"

AI 做了以下事情：

1. 打开页面
2. 设置窗口宽度为 1920px，截图
3. 设置窗口宽度为 1280px，截图
4. 设置窗口宽度为 768px，截图
5. 分析三张截图，指出问题所在

然后它甚至帮我定位到了具体的 CSS 代码行，并给出了修复建议。

## 对未来的思考

Chrome DevTools MCP 代表了一种趋势：**AI 正在从"顾问"变成"执行者"**。

以前，AI 只能给你建议："你可能需要检查网络请求"，"试试清除缓存"，"看看控制台有没有错误"。

现在，AI 可以自己执行这些检查，然后直接告诉你结论。

这让我想起了王小波说的：

> 不管我本人多么平庸，我总觉得对你的爱很美。

我对代码的爱可能很平庸——不够优雅，不够高效。但有了这些工具，至少我可以更快地找到问题，更快地修复它们，然后有更多时间去思考真正重要的事情。

## 结语

三场演讲听完，我的脑子里塞满了新概念：Antigravity、Gemini 3、Nano、Prompt API、MCP......
